# Digital Products Studio

> Building practical, reliable digital products that solve real operational problems.

---

## Overview

This repository contains the operating system for the Digital Products Studio.

The Studio is a structured product engineering environment for designing, building, releasing and maintaining lightweight digital products.

Rather than treating every new product as an isolated project, the Studio provides a shared set of principles, standards, templates and workflows that ensure every product is developed consistently.

The Studio itself is a product.

Its purpose is to make building future products repeatable.

---

# What We Build

The Studio focuses on practical digital products such as:

* Google Sheets systems

* Google Forms workflows
* Google Apps Script automations
* Dashboards
* Operational reporting tools
* Data collection systems

* Personal productivity systems

Products are designed to solve one operational problem exceptionally well before expanding in scope.

# Studio Principles

Every Studio product should:

* Solve a real problem.
* Be practical rather than impressive.
* Remain simple for users.
* Hide unnecessary complexity.
* Be professionally documented.
* Be modular.
* Be easy to customise.
* Work for a global audience where practical.
* Be maintainable over time.

Quality is preferred over quantity.

The Studio manages work using:

# Repository Philosophy

This repository does not primarily contain products.

It contains the system used to create products.

Individual products should have their own repositories once they reach active development.

The Studio repository remains the shared foundation that every product inherits.

---

# Versioning

The Studio follows semantic versioning where appropriate.

Major changes to Studio standards, workflows or governance should be documented through Architecture Decision Records (ADRs) and reflected in release notes.
